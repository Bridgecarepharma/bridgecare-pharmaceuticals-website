# Bridgecare v6.4.34 — Mobile Admin API

Adds a secure, read-only API layer for the Bridgecare Admin Android client.

## Included
- Mobile admin login using the existing ADMIN_PASSWORD and signed 8-hour admin token.
- Dashboard endpoint for today/month revenue, paid/pending orders, and recent orders.
- Orders endpoint with optional status filtering.
- Order-details endpoint with customer, delivery, product, payment and Paystack reference data.
- No storefront, checkout, payment, shipping, inventory, or existing browser-admin behavior changed.
