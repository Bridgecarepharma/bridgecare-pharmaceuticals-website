# Bridgecare Pharmaceuticals Website v6.6.1 — Two-Column Mobile Product Grid

Inspired by the useful catalogue pattern on Ome’s Beauty Mart, while retaining Bridgecare’s own healthcare branding.

## Improvements
- Keeps product cards in two columns on mobile phones.
- Shows the complete concise product description instead of cutting it to two lines.
- Keeps product image, category, name, price, Add to Cart and Details visible on every card.
- Aligns price and purchase controls toward the bottom of each card for a cleaner catalogue.
- Uses a lighter outlined card style and rounded Add to Cart button for clearer mobile shopping.
- Keeps the existing desktop/tablet layout, cart, checkout, Paystack, Lagos Pay on Delivery, shipping rules, admin and mobile-admin API unchanged.
