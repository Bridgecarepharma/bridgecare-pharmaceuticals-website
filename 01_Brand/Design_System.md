# Bridgecare Design System

## Core colours
- Bridgecare Blue: `#0056A6`
- Bridgecare Green: `#2E8B57`
- Ink: `#17324D`
- Soft background: `#F4F8FB`
- White: `#FFFFFF`

## Category accents
- Heart & Daily Wellness: `#C83E4D`
- Women's Wellness: `#C44D8B`
- Blood Sugar Wellness: `#D97706`
- Sickle Cell Wellness: `#7C3AED`
- Nerve Health: `#0F8B8D`
- Healthy Living: `#2E8B57`

## Typography
Use a modern system sans-serif stack for speed and accessibility:
`Inter, ui-sans-serif, system-ui, -apple-system, Segoe UI, sans-serif`

## Components
- Primary and secondary buttons
- Knowledge-centre cards
- Product cards
- Article cards
- Evidence badges
- Key takeaway callouts
- Newsletter form
- Footer navigation

## Accessibility
- Minimum 4.5:1 colour contrast for body text
- Visible keyboard focus states
- Semantic headings
- Alt text for informative images
- Large touch targets on mobile
