# Bridgecare Website v2.2.0 — Unified Admin Dashboard

This release consolidates the operational admin experience.

## Included
- Unified navigation with an active-page indicator
- Dashboard cards for orders, paid orders, pending payments, customers, revenue and stock alerts
- Quick links for products, prices, orders, customers and analytics
- Low/out-of-stock attention panel
- Recent orders table
- Newest customers and lifetime paid spend summary
- Existing products, prices, orders, customers and reports pages remain available

## Admin URLs
- `/admin`
- `/admin/products`
- `/admin/prices`
- `/admin/orders`
- `/admin/customers`
- `/admin/reports`
