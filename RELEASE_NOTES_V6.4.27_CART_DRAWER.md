# v6.4.27 — Mobile Cart Drawer

- Order now now adds the selected product and opens a mobile-first cart drawer instead of immediately pushing the customer into the checkout form.
- Header cart opens the same drawer.
- Cart drawer supports quantity changes, removal, suggested products, estimated subtotal and direct checkout.
- Free-delivery progress is shown prominently; 3+ packs unlock free nationwide delivery.
- Checkout CTA uses “Checkout ₦[amount] securely”.
- Existing checkout, Paystack initialization, shipping-zone logic, coupons, analytics and order persistence remain intact.
- Existing streamlined checkout keeps one Contact & delivery information section, reuses customer name/phone as recipient details, and does not request postal code.
