# Bridgecare v6.4.21 — Compact Mobile Above-the-Fold

This is a deliberately narrow mobile-only correction based on the storefront shown after v6.4.20.

## Changed
- Reduced mobile hero padding, headline size, description spacing and CTA height.
- Converted the mobile 2×2 trust block into a compact horizontal trust strip.
- Reduced mobile search and category-chip height and spacing.
- Removed sticky behaviour from the mobile shopping-tools block to avoid occupying persistent screen space.
- Reduced the free-delivery strip height.
- Pulled the product-section heading and first product row upward.

## Not changed
- Desktop layout.
- Product data or pricing.
- Order Now behavior.
- Cart/checkout flow.
- Add-more-products flow.
- Free-shipping calculation or delivery-method logic.
- Paystack integration.
- Meta/TikTok analytics and purchase-event logic.
- Admin functionality.
