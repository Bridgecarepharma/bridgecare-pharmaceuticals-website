# v6.4.21 — iHerb-inspired mobile storefront

This release keeps Bridgecare's own visual identity while making the phone shopping experience denser and more commerce-first.

## Mobile changes
- Compact sticky header and smaller official logo.
- Shorter hero; product catalogue appears much sooner.
- New prominent product search entry point.
- Horizontally scrollable category chips.
- Two-column compact product catalogue on phones.
- Smaller product imagery, tighter descriptions and prominent Order now buttons.
- Trust strip compressed further.
- Supporting brand/education sections reduced in visual weight.
- Existing WhatsApp, cart, Order Now checkout, Paystack, shipping, Meta and TikTok logic preserved.

Desktop presentation is intentionally left substantially unchanged.
