# CMS Content Model

Recommended platform: WordPress with a custom block theme and structured custom post types, or an equivalent headless CMS.

## Taxonomies
- Health category
- Evidence level
- Ingredient type
- Product category
- Audience

## Workflow statuses
Draft → Editorial review → Scientific review → Regulatory review where applicable → Approved → Published → Scheduled review → Archived.

## Permissions
Editors may draft and edit. Scientific reviewers approve educational accuracy. Regulatory reviewers approve product communication. Only administrators publish regulated content.
