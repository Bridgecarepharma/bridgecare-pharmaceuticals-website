# Bridgecare Website Functional Specification v1.0

## Roles
- Visitor
- Content editor
- Scientific reviewer
- Administrator

## Global features
- Responsive navigation
- Site-wide search
- Breadcrumbs
- Newsletter signup
- Social sharing
- Related-content engine
- Contact and distributor forms
- Adverse-event reporting pathway
- Analytics and consent controls

## Content types
- Standard page
- Product
- Article
- Ingredient
- Health topic
- Download
- Video
- Team member
- Event

## Article fields
Title, slug, excerpt, hero image, category, author, reviewer, review date, evidence level, body, FAQs, references, related products, related articles, disclaimer and SEO fields.

## Product fields
Name, slug, category, short description, approved claims, ingredients, directions, warnings, storage, regulatory details, pack images, leaflet, FAQs, related articles and SEO fields.

## Forms
- General contact
- Distributor enquiry
- Medical-information request
- Adverse-event report
- Newsletter signup

All forms require validation, spam protection, consent text and secure data handling.
