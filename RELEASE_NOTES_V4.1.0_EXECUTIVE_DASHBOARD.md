# Bridgecare v4.1.0 — Executive Dashboard

## Added
- Today's revenue and orders
- Current-month revenue and average order value
- Pending-order and delivered-today indicators
- Total and repeat customer indicators
- Live stock-alert count
- Fourteen-day revenue chart
- Top-product revenue and unit-sales ranking
- Quick links for orders, inventory, prices, shipping, CRM and reports
- Responsive dashboard layout for mobile and desktop

## Database
No migration is required. The dashboard uses the existing Order, OrderItem, Customer and Inventory records.

## Deployment
Commit and push to GitHub. Netlify can deploy with the existing environment variables.
